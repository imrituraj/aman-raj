# Aman Raj · portfolio

A clean, editorial-style portfolio built with React + Vite.

## Run it

```bash
npm install
npm run dev
```

## Edit content

Everything (intro, facts, HelpMeMan, journey, interests, and the note in the footer) lives in `src/data.js`.
Images are in `public/` (`aman.jpg`, `helpmeman-launch.jpg`, `hm-mark.png`).

## Deploy (free)

- **Vercel / Netlify:** import the folder, build command `npm run build`, output `dist`.
- Or locally: `npx vercel` and follow the prompts.
